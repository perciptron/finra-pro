# fin-ra.pro

Главный домен FIN-RA. Один лендинг «Инвест-зарплата» в корне плюс юридические документы.

Хостинг — GitHub Pages, деплой автоматически при пуше в `main`.

## Структура

```
/                      лендинг «Инвест-зарплата» (перенесён с guides.fin-ra.pro/Insalary)
/policy-dt/            Политика обработки персональных данных
/terms-of-use/         Пользовательское соглашение
/juristic-documents/   Правовая информация (оферта)
/isalary/              картинки лендинга
/tg/*                  обход блокировки t.me — обрабатывается 404.html
```

## Формы

Лид-форма — Salebot, project `317313`, guid `9adb4552388bf0b240d3e7b2010e65b9`
(тот же, что у `guides.fin-ra.pro/isalary`).

Обязательные для формы скрипты уже подключены:

- `tg-intercept.js` — обход блокировки `t.me` и починка мёртвых кнопок во встроенном браузере Telegram
- `salebot-guard.js` — не даёт открыться пустой модалке, если форма Salebot не догрузилась

## Юридические документы

Собраны из исходников школы (Google Docs / .docx) скриптом, текст перенесён дословно.
Нумерация пунктов сверена с оригиналом. Внутри самих документов остались ссылки на
`fin-ra.ru` и почта `finracenter@fin-ra.ru` — это текст договора, менять его может только
владелец/юрист.
